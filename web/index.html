Every program that sent or received traffic. Pick what each may do. With Unlisted apps: Block only apps set to Allow or Limit get through (the built-in default whitelist always passes).

First matching rule wins, so the order matters (reordering is off while a filter is active). Rules with no app apply to every app. The built-in default whitelist (DHCP, DNS, ...) is checked before all of these - see Defaults.

Built-in default whitelist: basic Windows connectivity that is always allowed first - before your rules and before "Unlisted apps: Block" - so a rule on svchost.exe or a block-everything setup can't break your connection. They are matched by protocol/port (DHCP and DNS run as services inside svchost.exe, so they can't be told apart by program). Untick an item to stop whitelisting it.

Advanced: the raw rules file. Saving validates everything first; nothing changes if there is an error.
